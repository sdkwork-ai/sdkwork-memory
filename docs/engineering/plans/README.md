# plans

Implementation plans for `sdkwork-memory`, governed by `DOCUMENTATION_SPEC.md` section 2.

A plan describes intended work and its sequencing. Once the work lands, the durable outcome belongs
in the relevant contract, spec, or architecture document — the plan stays as history and is not
retro-edited.

There are no plan documents here yet. The earlier implementation plans live in
`docs/superpowers/plans/`, which are migration stubs pointing at `docs/architecture/tech/`; new
plans belong in this directory.
