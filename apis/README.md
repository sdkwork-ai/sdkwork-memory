# APIs

`apis/` contains authored API contract sources, route materialization inputs, examples, changelogs, and validation fixtures for SDKWork Memory.

Authoritative OpenAPI for phase 1 is the per-surface `apis/<surface>/memory-<surface>-api.openapi.json` file in this directory, generated by `node tools/materialize_phase1_contracts.mjs` and indexed through `apis/authority-manifest.json`. The `sdks/*/openapi/*.openapi.json` files are byte-identical generation-input mirrors of these authorities — edit the materialize tool, never the mirrors.

Domain workspace skeleton:

- `apis/open-api/intelligence/memory/`
- `apis/app-api/intelligence/memory/`
- `apis/backend-api/intelligence/memory/`

Related specs: `../sdkwork-specs/API_SPEC.md`, `WEB_FRAMEWORK_SPEC.md`, `SDKWORK_WORKSPACE_SPEC.md`.
